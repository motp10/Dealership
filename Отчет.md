## Метрики приложения

Приложение использует Spring Boot Actuator и Micrometer с Prometheus registry. Метрики доступны по адресу `http://<backend>:8091/actuator/prometheus`. Сбор выполняет VictoriaMetrics Single через Kubernetes Service/Endpoints discovery по `prometheus.io/*` annotations на сервис `backend` и сервис `postgres`.

Добавлены бизнес-счётчики успешных операций. Счётчики регистрируются при старте (аннотация `@PostConstruct`) и увеличиваются только после успешного выполнения операции:

- `dealership_cars_total` — созданные автомобили.
- `dealership_cars_deleted_total` — удалённые автомобили.
- `dealership_details_total` — созданные детали.
- `dealership_details_deleted_total` — удалённые детали.
- `dealership_users_total` — созданные пользователи.
- `dealership_users_deleted_total` — удалённые пользователи.
- `dealership_configuration_orders_total` — созданные заказы на автомобиль с конфигурацией.

Счетчики добавлены в контроллеры:
- `src/main/java/ru/matvey/dealership/presentation/controllers/CarsController.java`, 
- `src/main/java/ru/matvey/dealership/presentation/controllers/DetailController.java`
- `src/main/java/ru/matvey/dealership/presentation/controllers/UserControllerController.java`
- `src/main/java/ru/matvey/dealership/presentation/controllers/ConfigurationCarOrderController.java` 


PostgreSQL экспортирует метрики через `postgres-exporter` в отдельном контейнере на порту `9187`. Доступ к базе exporter получает из Secret `postgres-secret`; endpoint `/metrics` обнаруживается через Service `postgres`, а успешность подключения отражает `pg_up`.

VictoriaMetrics Single установлен Helm-релизом `vmsingle-monitoring` из официального репозитория `vm` в namespace `monitoring`. Встроенный scrape у Single выключен, метрики обнаруживает и собирает отдельный `vmagent-monitoring` и отправляет их в Single через remote-write. Настройки сохранены в `k8s/monitoring/vmsingle-values.yaml` и `k8s/monitoring/vmagent-values.yaml`.
