## Мониторинг

1. Получение списка автомобилей: `GET /api/cars`.
2. Создание заказа на автомобиль: `POST /api/stockCars`.

Мониторинг реализован с помощью:

Пробера black-box-exporter который взаимодействует с vmagent. Делает запросы на два адреса


## 1. SLI — измеряемые показатели

1. Доступность `GET /api/cars`.

  Доля успешных проб GET /api/cars за последние 5 минут, в процентах
   
   Формула: `SLI = успешные пробы / все пробы * 100%`
```
   label_replace(
      avg_over_time(probe_success{job="backend-prober"}[5m]) * 100,
      "metric", "SLI availability", "", ""
    )
    or
    label_replace(vector(99.5), "metric", "SLO 99.5%", "", "")
    or
    label_replace(vector(99), "metric", "SLA 99%", "", "")
```

2. Успешность `POST /api/stockCars`.

Доля успешных проб создания заказа POST /api/stockCars за последние 5 минут, в процентах.

   Формула: `SLI = успешные POST / все POST * 100%`
```
label_replace(
  avg_over_time(probe_success{job="stock-car-order-prober"}[5m]) * 100,
    "metric", "SLI POST success", "", ""
  )
  or
  label_replace(vector(99), "metric", "SLO 99%", "", "")
  or
  label_replace(vector(98), "metric", "SLA 98%", "", "")
```

3. Доля быстрых ответов `GET /api/cars` (менее 500 мс).

Доля успешных проб GET /api/cars, длительность которых меньше 15 мс

   Формула: `SLI = пробы быстрее 500 мс / все пробы * 100%`
  ```
label_replace(
  avg_over_time(
    (
      (probe_duration_seconds{job="backend-prober"} < bool 0.015)
      and
      (probe_success{job="backend-prober"} == 1)
    )[5m:]
  ) * 100,
  "metric", "SLI under 100s", "", ""
)
or
label_replace(vector(95), "metric", "SLO 95%", "", "")
or
label_replace(vector(90), "metric", "SLA 90%", "", "")
```

## 2. SLO — целевые показатели

- Доступность GET /api/cars: не менее 99,5% успешных проб за 30 дней.

- Успешность POST /api/stockCars: не менее 99% успешных запросов за 30 дней.

- Доля быстрых ответов GET /api/cars: не менее 95% успешных проб должны отвечать быстрее 15 мс за 30 дней.

## 3. SLA — обязательства

- Доступность GET /api/cars: не ниже 99% за месяц (SLO — 99,5%). Значение ниже 99% считается нарушением SLA.

- Успешность POST /api/stockCars: не ниже 98% за месяц (SLO — 99%). Значение ниже 98% считается нарушением SLA.

- Доля быстрых ответов GET /api/cars: не ниже 90% за месяц (SLO — 95%). Значение ниже 90% считается нарушением SLA.
