## Исправляния
- Исправлен трансформер в векторе, который раньше убирал слишком много информации из логов
- Раньше было много логов с неизвестным уровнем т.к. livenessProbe для фронта слал в него get запросы и ответы логировались, сейчас изменен конфиг nginx добавлен адрес /healthz и отключен access_log off;
```
location /healthz {
        access_log off;
        return 200 "ok\n";
        add_header Content-Type text/plain;
    }
```
- В фильтре заменяется уровень warning на warn чтобы был единый страндарт уровней важности

## vmalert
для vmalert был создан deployment config-map и service каждые и тоже самое для alertManager. В config-map vmalert добавлено правило TooManyApplicationErrors оно проверяется каждую минуту, срабатывает, если за последние 5 минут найдено более 10 записей логов с уровнем error, и это условие сохраняется непрерывно в течение 2х минут. AlertManager шлет алерты на почту указанную в config-map с помощью SMTP. Для этого в secret.yaml указан пароль от SMTP (в данный момент там указан просто пример пароля).
