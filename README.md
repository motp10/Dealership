# Dealership

## Запуск и Swagger

Требования: JDK 21, запущенный Docker с Docker Compose. Порты 8080 и 8888 должны быть свободны.
Укажите JDK 21 через `JAVA_HOME` или Gradle JVM в IDE. Абсолютный путь к JDK в репозитории не хранится.
Например, на текущей Linux-машине: `export JAVA_HOME=/usr/lib/jvm/java-21-openjdk`.

```sh
./gradlew bootRunLocal
```

Команда поднимает PostgreSQL из `docker/docker-file-dependency.yaml`, затем запускает приложение.
Liquibase автоматически применяет миграции базы данных.
В IntelliJ IDEA можно обновить Gradle-проект и выбрать конфигурацию **Dealership + Swagger**.
В других IDE команду можно выполнить во встроенном терминале.

- Swagger UI: http://localhost:8080/swagger-ui.html
- OpenAPI JSON: http://localhost:8080/v3/api-docs

В Swagger раскройте нужную операцию, нажмите **Try it out**, заполните параметры или JSON
и нажмите **Execute**. Запросы выполняются к реальной локальной базе данных и могут изменять данные.

Остановка приложения: `Ctrl+C` в терминале или Stop в IDE. База продолжает работать;
для её остановки с сохранением данных:

```sh
docker compose -f docker/docker-file-dependency.yaml stop
```

Обычный `./gradlew bootRun` требует переменных `DB_URL`, `DB_USER`, `DB_PASSWORD` и заранее выполненных миграций.
Локальный `bootRunLocal` использует демонстрационные настройки и включает Swagger.

Сборка, контейнерный запуск, миграции и соответствие 12 факторам: [docs/twelve-factor.md](docs/twelve-factor.md).

## Создание машины

Для `POST /api/cars` поле `baseCost` обязательно и должно быть неотрицательным.
Детали подбираются по типу, значению и совместимости с моделью. `wheel` необязательно:
если оно передано, подходящие колёса должны уже существовать в каталоге деталей.
Цена автомобиля складывается из базовой цены и стоимости выбранных деталей.

Пример создания машины на начальных данных:

```json
{
  "brand": "BMW",
  "model": "M5",
  "bodyType": "Sedan",
  "paint": "Black",
  "fuel": "Petrol",
  "transmission": "Automatic",
  "driveLayout": "AWD",
  "baseCost": 100000
}
```

Пустые обязательные поля, отрицательная цена и недоступная или несовместимая
комплектация возвращают HTTP 400 без добавления машины.

## Известные ограничения API

- `GET /api/details` может возвращать 500: в начальных данных есть тип `SPOILER`,
  для которого отсутствует соответствующая Hibernate-сущность.
- Некоторые GET-операции в текущих контроллерах используют `@RequestBody`.
  Отправка тела GET-запроса из браузерного Swagger UI не поддерживается;
  для таких операций потребуется исправить привязку параметров в контроллере.
